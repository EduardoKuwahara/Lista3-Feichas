# Lista 3 - Guia rapido

Projeto com 4 apps Flutter e 1 backend Node.js.

## Pre-requisitos

- Flutter instalado
- Node.js instalado

## 1) Rodar backend

Abra um terminal na pasta backend e execute:
```
npm install
npm run start
```

API padrao: http://localhost:3000

## 2) Rodar os apps Flutter

Abra outro terminal e rode o app desejado:

```
cd <nomedoapp>
flutter pub get
flutter run -d windowns
```
